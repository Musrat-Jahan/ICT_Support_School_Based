
# School IT Support: Troubleshooting & Knowledge Base

A practical IT support knowledge base covering common technical issues in a school environment, including laptops, desktops, printers, Microsoft 365, network connectivity, classroom audiovisual equipment, and IT asset management.

This repository documents historical IT support cases, their reported symptoms, recorded resolutions, and troubleshooting topics for learning and reference.

##  Project Overview

**Environment:** School ICT Support  
**Focus:** IT Helpdesk, Desktop Support, Hardware Troubleshooting and IT Asset Management  
**Source:** Historical school IT support records

### Objectives

- Organise common school IT support issues.
- Document reported problems and their resolutions.
- Build a searchable troubleshooting reference.
- Improve understanding of school ICT operations.
- Develop practical IT support and technical documentation skills.

|---|---|---|
